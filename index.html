MYtube

관심 유튜브 채널을 주제별 폴더로 모으고, 폴더 안에서 바로 재생하세요. X·Facebook은 URL 링크 버튼으로 함께 정리합니다.

이 주소는 앱 실행 주소가 아닙니다

github.io는 정적 파일만 호스팅합니다. MYtube는 Next.js + Google 로그인 + DB가 필요한 웹앱이라 GitHub Pages에서 동작하지 않습니다. 그래서 예전에는 README 문서만 보였습니다.

로컬에서 화면 보기

  1. 저장소를 클론한 뒤 npm install
  2. .env에 Google OAuth 값 설정
  3. npm run dev 실행
  4. 브라우저에서 http://localhost:3000/demo (미리보기) 또는 http://localhost:3000

실제 배포는 어디에?

Next.js 앱은 Vercel + PostgreSQL(Neon / Vercel Postgres)에 배포해야 합니다. GitHub Pages로는 로그인·API·DB를 돌릴 수 없습니다. 자세한 단계는 저장소 README의 「Vercel 배포 가이드」를 보세요.
